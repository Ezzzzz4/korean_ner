Other files already present in this directory belong to the **historical experiment**, including `metrics.json`, `classification_report.txt`, `error_analysis.txt`, `per_entity_f1.png`, the original confusion matrices, calibration plots, and `attention/` images. They are retained as project history. They do not report the selected KF-DeBERTa model's performance.

Attention maps are descriptive transformer statistics, not causal explanations. The corrected calibration tool measures emission-classifier confidence, not a CRF sequence probability. Historical error counts came from the earlier matching procedure and have not been carried forward as new measurements.
